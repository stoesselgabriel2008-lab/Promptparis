CONVENTIONS DE CALCUL (identiques pour toutes les lignes ; calculs faits en code)
- Probabilité de référence : retrait de marge « power » sur le marché Pinnacle complet à deux issues. Contrôle par la méthode multiplicative : l'écart entre les deux méthodes reste sous 0,8 point partout.
- p_ret = p_ref. Aucun ajustement : aucune information datée n'est postérieure aux cotes.
- Fourchette : ±2 points ; ±3 points sur base Winamax seule (I1).
- États de paiement Winamax :
  · gain = 97 % × p_ret ;
  · annulé = 3 % (abandon) ;
  · perte = le reste.
  Les 3 % sont une hypothèse d'ordre de grandeur : repère publié d'environ 3 % des matchs en deux sets gagnants terminés par un abandon (étude PLOS ONE 2024), appliqué à tous les matchs, double compris. Avec 0 % ou 6 %, les tickets retenus restent les mêmes.
- EV centrale = gain × cote + annulé − 1.
- EV prudente : 2 points (3 pour I1) retirés au gain et ajoutés à la perte, l'état annulé ne bougeant pas.
- Combinés : matchs différents, jambes indépendantes. (1 + EV) du ticket = produit des (1 + EV) des jambes ; une jambe annulée compte pour 1. Chance de gain plein = produit des gains. Chance de profit = toutes les jambes non annulées gagnent (calculée sur tous les états).
- Qualité :
  · Q1 = cote Winamax observée, référence Pinnacle, aucun statut incertain, règle vérifiée.
  · Q2 = base Winamax seule (I1), ou extérieur sous la pluie avec une règle de report non fournie (C2, C4) ; hypothèse prudente pour le report : pari maintenu jusqu'au match ou annulé, ticket bloqué entre-temps.
- Tier : calculé sur la chance de gain plein (S ≥ 70 %, A 60–70, B 50–60, C 40–50, D < 40) ; deux tiers si la fourchette traverse une frontière.
- Règle de décision R★ : classement par EV prudente ; groupe de tête à moins d'un point de la meilleure ; dans ce groupe, le moins de jambes, puis la meilleure qualité, le moins de conditions, et enfin la meilleure EV prudente.
